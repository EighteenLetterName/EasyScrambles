INTRODUCTION


When I learned about speedcubing, I wanted to learn how to quickly solve a Rubik's Cube.

I chose the CFOP method to solve the rubik's cube for speed

Once, while training, I fell out easy scramble and I wanted to always get such scrambles

I started looking on the Internet easy scrambles, but soon I tried them all.

Then I started looking generators for easy scrambles but in the end I didn't find them.

I got the idea to delve into the study of programming in order to code the generator myself

Now my little dream has come true and I'm happy to share the code with you for free

============================================================

ABOUT


Generator of 3x3 easy scrambles which are solved using the CFOP in ~26 moves

— Easy cross

— 3-4 move every F2L pare

— easy OLL

— PLL skip
